 │ 설계 (확정)                                                                                                                                               │

 │ 1. 구조적 규모 비대칭 (시드·상한)                                                                                                                         │
 │                                                                                                                                                           │
 │ preset_worlds.json (preset_worlds.json) + main.py (main.py) 시드 로직:                                                                                    │
 │ • 국가별 경제 규모 배수 country_scale (인구·기업 상한·초기 시설 단계에 곱함). 기본은 월드 내 상대 서열만 두고, Cold War ID에 약한 힌트만 유지 (예:        │
 │   상위권 1.6~2.2×, 중위 1.0×, 하위 0.45~0.7×).                                                                                                            │
 │ • MAX_COMPANIES_PER_COUNTRY를 전역 상수 대신 국가 스케일 기반 상한으로 바꿈 (예: max(1, round(2 * scale))).                                               │
 │ • 워밍업 시드 시설 단계를 scale에 연동해 초기 용량 격차를 만듦.                                                                                           │
 │                                                                                                                                                           │
 │ 2. 산업 점유율: 파워로 + 점성                                                                                                                             │
 │                                                                                                                                                           │
 │ company_product_attractiveness (main.py) / 배분:                                                                                                          │
 │ • 매력도에 규모 항 추가: attract *= (1 + κ · log1p(capacity)) 또는 기존 용량 점유율의 멱법칙(share^α, α≈1.3~1.6)로 재가중 → 이미 큰 기업이                │
 │   수요·증설에서 유리 (승자독식).                                                                                                                          │
 │ • ALLOC_SHARPNESS를 직종 공용 1.7에서 자본집약/하이테크 직종만 상향 (반도체·소프트웨어·차량 등 2.2~2.6), 원자재·농업은 유지.                              │
 │ • 목표 점유율 EMA: 매주 sticky_share = λ·sticky + (1-λ)·target, λ≈0.85~0.92 (반감기 수개월). 실제 수요 배분·건설 판단은 sticky를 사용.                    │
 │ • 치킨게임 진입 문턱을 상위 점유율 기업에 더 관대하게 / 하위는 더 빨리 축소 → 하위권 난립 억제.                                                           │
 │                                                                                                                                                           │
 │ 3. 시총: 펀더멘털 계층 + 유동성 베타                                                                                                                      │
 │                                                                                                                                                           │
 │ 산업 → 이익 → 시총이 계층을 유지하도록:                                                                                                                   │
 │ • 공정가/시총이 규모(매출·장부·이익)에 비례하도록 유지하되, 소형주·후발국 종목에 할인 배수(낮은 fair PER/PBR 밴드)를 둬 시총이 용량보다 더 가파른         │
 │   파워로가 되게 함.                                                                                                                                       │
 │ • stock_price_change_from_orders (main.py)에 시총 가중 충격 흡수: effective_flow /= (1 + γ · log1p(mcap / median_mcap)) — 대형주는 같은 주문에도 %        │
 │   변동이 작음 (현실 유동성).                                                                                                                              │
 │ • 국가 팩터 stock_draw_country_market_factor (main.py)를 순수 노이즈가 아니라 국가 GDP/신용/금융쇼크 강도에 약한 편향을 섞어, 펀더멘털 약한 나라의        │
 │   “랜덤 급등으로 시총 1위”를 줄임.                                                                                                                        │
 │ • 국가 시총 점유율 표시/히스토리에 4~13주 EMA를 병행해 UI·랭킹 체감 뒤집힘을 완화 (원시 주간 값은 유지).                                                  │
 │                                                                                                                                                           │
 │ 4. 국력 지표 (복합, 느리게 변함)                                                                                                                          │
 │                                                                                                                                                           │
 │ 새 헬퍼 (예: country_power_index):                                                                                                                        │
 │ • 가중: 명목 GDP + 산업 용량(주요 직종 sticky share) + 상장 시총 EMA + (선택) 신용점수.                                                                   │
 │ • 주간 스냅샷을 EMA로 기록 → “국력 순위가 매주 바뀌지 않음”.                                                                                              │
